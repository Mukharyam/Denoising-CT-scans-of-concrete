## 🎯 Проблематика и цель исследования

При томографическом контроле промышленных материалов (бетонных кернов) ключевым фактором является время экспозиции. Ускоренное сканирование (низкая доза излучения) кратно удешевляет процесс, но приводит к возникновению **тяжелого квантового шума и кольцевых артефактов**.

* **Главный диагностический риск:** Шум маскирует субпиксельные дефекты — микротрещины шириной 1–2 пикселя и воздушные поры, либо сам шум ошибочно классифицируется как повреждение.
* **Тупик классической фильтрации:** Медианные, билатеральные и вейвлет-фильтры работают через локальное усреднение, неизбежно стирая микротрещины («мыло») или создавая артефакты Гиббса на границах зерен заполнителя.

**Цель проекта:** Разработка легковесной, устойчивой нейросетевой архитектуры глубокого обучения для эффективного подавления шума в КТ-снимках сверхвысокого разрешения с гарантированным сохранением субпиксельной топологии микротрещин без эффекта размытия.

## 📊 Специфика данных и физика шума (EDA)

В качестве данных использовался парный датасет томограмм бетонных кернов:
* **Формат:** 16-битные TIFF снимки сверхвысокого разрешения (**$3067 \times 3067$ пикселей**).
* **Пары:** `Low-Stat` (зашумленный скан при ускоренном облучении) $\leftrightarrow$ `High-Stat` (эталон длительного сканирования).

```
   Z-ось (Глубина)
    0                400                             2430           2816
    [  Краевой воздух  |====== Физическая толща бетона ======|  Оснастка  ]
    [  (НЕВАЛИДНО)    |   ВАЛИДНЫЙ ДИАПАЗОН ДЛЯ ОБУЧЕНИЯ   | (НЕВАЛИДНО) ]
```

### Ключевые открытия разведочного анализа (`noise_isolation.ipynb`):
1. **Фильтрация Z-оси:** Срезы $[0 \dots 399]$ и $[2430 \dots 2816]$ отброшены из-за преобладания воздуха и крепежной оснастки (где $\sigma$ шума искажена). В работу взят строго валидный массив $[400 \dots 2430]$ (2030 пар).
2. **Гипер-Лапласовское распределение шума:** Анализ остатка $\Delta = I_{noisy} - I_{clean}$ доказал, что шум подчиняется распределению **Лапласа** (сверх-острый пик в нуле и тяжелые экспоненциальные хвосты), а не Гаусса. 
   > **Следствие:** Применение стандартного MSE (L2) лосса математически гарантирует «мыло» из-за квадратичного штрафа на тяжелых хвостах. Требуется L1-подобная оптимизация.
3. **Динамика $\sigma$:** Стандартное отклонение шума меняется по глубине керна на $\sim 10\%$ из-за вариации плотности заполнителя (гравий/песок/цемент).

## 🏗 Эволюция архитектурных подходов

В ходе проекта были последовательно исследованы три парадигмы:

```
┌─────────────────────────┐     ┌─────────────────────────┐     ┌─────────────────────────┐
│     1. U-Net Baseline   │     │    2. SCUNet (Hybrid)   │     │3. Guided Restormer (Ours│
│  • Чистая CNN (31.0M)   │ ──► │ • CNN + Swin (17.9M)    │ ──► │ • Channel Attn (11.6M)  │
│  • Global Residual      │     │ • Локальный + нелокальн.│     │ • MDTA + GDFN           │
│  • Локальный контекст   │     │ • Бутылочное горло VRAM │     │ • Canny Prior (Guided)  │
└─────────────────────────┘     └─────────────────────────┘     └─────────────────────────┘
```

### 1. Сверточный U-Net с Global Residual (`31.0M параметров`)
* **Принцип:** Прогнозирование остаточного шума $I_{clean} = I_{noisy} - \text{Noise}$.
* **Проблема:** Ограниченное рецептивное поле сверток $3 \times 3$ не позволяет сети оценивать протяженные микротрещины целиком.

### 2. Гибридный SCUNet (`17.9M параметров`)
* **Принцип:** Симбиоз Residual CNN (для удержания локальных граней) и Swin Transformer (для подавления нелокального шума в окнах внимания).
* **Проблема:** Оконное внимание Swin в параллель со свертками требует высоких затрат VRAM на больших патчах ($512 \times 512$), приводя к OOM.

### 3. Финальный SOTA: Guided RestormerCT (`11.6M параметров`)
Специализированный трансформерный автоэнкодер для задач реставрации высокого разрешения:
* **MDTA (Multi-Dconv Head Transposed Attention):** Внимание вычисляется **между каналами признаков** ($C \times C$), а не пространственными токенами ($HW \times HW$). Это снижает сложность вычислений со строго квадратичной до **линейной** относительно разрешения.
* **GDFN (Gated-Dconv Feed-Forward Network):** Управляемое вентильное умножение признаков (GELU-шлюз) с расширением каналов в $2.66\times$.
* **Архитектурный граф:** Представлен в файле `restormer_architecture`. Включает 4 уровня энкодера-декодера с глубинами блоков `[2, 3, 3, 4]`, числом голов `[1, 2, 4, 8]` и базовой размерностью $C=48$.

## 🛡 Пайплайн предобработки и Guided-концепция

Вместо традиционной слепой очистки (Blind Denoising) реализован **Guided-подход**:

1. **Генерация структурного прайора Canny (`canny.ipynb`):**
   * К полноразмерному 16-битному снимку применяется адаптивное выравнивание гистограммы CLAHE и фильтр билатерального сглаживания.
   * Детектор Canny ($T_1=65, T_2=140$) выделяет границы.
   * Анализ компонент связности (`connectedComponentsWithStats`) фильтрует круглую рябь цемента, сохраняя только вытянутые линии трещин (aspect_ratio ≥ 2.2) и крупные включения ($\text{area} \ge 350$).
2. **2-канальный вход Restormer:**
   Входной тензор формируется объединением `[Noisy CT (канал 0) + Canny Mask (канал 1)]`. Механизм MDTA использует канал Canny как пространственный «щит», блокируя размытие пикселей на границах дефектов.

## ⚙️ Аугментация и многоуровневая функция потерь

### Физически обоснованная аугментация (D4 + Gamma)
* ❌ **Отказ от MixUp / CutMix:** В задачах попиксельной реконструкции смешивание создает эффект «двойной экспозиции», разрушая фазовый спектр, а CutMix генерирует искусственные прямоугольные швы с бесконечным градиентом.
* ❌ **Отказ от Random Crop:** Фиксированные честные патчи $256 \times 256$ сохраняют пространственную непрерывность длинных трещин.
* ✅ **Группа симметрий D4:** 8 ортогональных трансформаций (4 поворота на $90^\circ \times 2$ флипа) без интерполяционных искажений.
* ✅ **Гамма-коррекция ($\gamma \in [0.8 \dots 1.2]$):** Моделирует нестабильность рентгеновской трубки:
  $$I_{aug} = \text{clip}(I^\gamma, 0.0, 1.0)$$

### Комбинированная функция потерь (FullHybridCTLoss)
$$\mathcal{L}_{Total} = w_{charb} \cdot \mathcal{L}_{Charbonnier} + w_{edge} \cdot \mathcal{L}_{Edge}$$

1. **Charbonnier Loss ($w_{charb} = 1.0$):**
   $$\mathcal{L}_{Charb} = \frac{1}{N} \sum_{i=1}^N \sqrt{(\hat{y}_i - y_i)^2 + \epsilon^2}, \quad \epsilon = 10^{-3}$$
   Дифференцируемое сглаженное приближение $L_1$-нормы. По принципу максимального правдоподобия (MLE) идеально оптимизирует гипер-Лапласовский шум КТ без размытия.
2. **Sobel Edge Loss ($w_{edge} = 0.15$):**
   Штраф за несовпадение пространственных производных, вычисляемый сверткой с ядрами Собеля $S_x$ и $S_y$:
   $$\mathcal{L}_{Edge} = \frac{1}{N} \left( \|\nabla_x \hat{y} - \nabla_x y\|_1 + \|\nabla_y \hat{y} - \nabla_y y\|_1 \right)$$
   Откалиброванный вес $0.15$ форсирует субпиксельную резкость микротрещин без усиления шума на однородном цементе.

## 🚀 Инженерные и аппаратные оптимизации

* **Буферный датасет (`CTBufferedDataset`):**
  * Устранена проблема 64-кратного чтения снимков с диска. Полноразмерный TIFF $3067 \times 3067$ считывается ровно **1 раз** за эпоху.
  * Картинки кэшируются в RAM в компактном формате `uint8` (всего 9.4 МБ на снимок). Потребление RAM снижено с **80 ГБ до 150 МБ** на буфер из 8 снимков.
* **Zero-Garbage GPU Buffers:** Ядра Собеля зарегистрированы через `register_buffer`, исключая межпроцессорные пересылки в цикле обучения.
* **Mixed Precision (AMP FP16):** Обучение стабилизировано через `torch.cuda.amp.GradScaler(enabled=True)` под Tensor Cores.
* **Бесшовный инференс (Hann Window Stitching):**
  В `metrics_restormer.ipynb` сборка полноразмерного снимка из перекрывающихся патчей выполняется с взвешенным 2D-окном Ханна:
  $$W(x, y) = w_{hanning}(x) \otimes w_{hanning}(y)$$
  Это полностью устраняет граничные сеточные артефакты на стыках патчей.

### Анализ профилей интенсивности (Line Profiles)
В `metrics_restormer.ipynb` реализован радиальный анализ срезов (аналог преобразования Радона). 1D-профили подтверждают, что Restormer сохраняет вертикальные обрывы на границах трещин и пор, срезая исключительно пилообразные высокочастотные зубцы шума на однородных плато.

### Стресс-тестирование на OOD данных (`noise_robustness_results.csv`)
Модель была протестирована на искусственно модулированном шуме ($\sigma_{fraction} \in [0.01 \dots 0.3]$). Guided Restormer продемонстрировал стабильную сходимость без распада структуры изображения даже при 3-кратном превышении стандартного уровня шума.
